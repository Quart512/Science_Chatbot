# 사용법 가이드

AIsaac을 처음 받아서 쓰는 사람을 위한 화면별 사용법. "왜 이렇게 만들었는지"는 여기 없다 — 그건 [docs/RoadMap.md](RoadMap.md)의 설계 노트에 있다. 여기는 **지금 화면에서 무엇을 누르면 무엇이 되는가**만 다룬다.

앱을 아직 안 띄웠다면 [README.md의 "내려받아 쓰기"](../README.md#내려받아-쓰기)를 먼저 본다.

## 화면 구성

왼쪽에 네비게이션, 가운데에 지금 고른 화면, 오른쪽에 항상 떠 있는 챗 패널 — 3분할이다.

- **왼쪽 네비**: 홈 · 💬 챗봇 · 🧬 연구 워크플로우 · 📄 논문 · 🔬 관심사 · 🧪 실험도구 · 📝 지식 노트 · ⚙️ 설정. 맨 위 `✕`로 네비 전체를 접을 수 있고(좌상단 `☰`로 다시 펼침), 챗봇·연구 워크플로우 항목 옆의 `▾`/`▸`로 그 아래 세션 목록만 접었다 펼 수 있다.
- **오른쪽 챗 패널**: 다른 화면을 보면서 동시에 과학 질문을 할 수 있는 상시 창. `✕`로 닫으면 우상단에 "💬 챗 열기" 버튼만 남는다. 항상 **가장 최근에 쓴 대화**를 이어서 보여준다 — 왼쪽 챗봇 화면과 세션을 공유하므로 어느 쪽에서 대화를 이어가도 서로 반영된다.
- **홈**: 아직 자리표시 화면이다(백엔드 연결 확인용). 실제 기능은 전부 왼쪽 네비의 다른 항목에 있다.

## 과학 질문하기 (챗봇)

오른쪽 챗 패널이나 왼쪽 "💬 챗봇" 화면, 어느 쪽을 써도 같은 대화다.

1. 상단 드롭다운에서 모델(`gemini`/`claude`/`Qwen-tuned` — 마지막은 로컬 서빙 필요)과 노력 수준(`low`/`medium`/`high`, 검색 문서 수·재시도 횟수를 한 번에 정한다)을 고른다.
2. 입력창에 질문을 쓰고 전송. 등록해둔 논문·강의록과 필요하면 웹 검색을 근거로 답하고, 스스로 점검해서 부족하면 다시 찾아 고쳐 쓴다 — 그래서 첫 답이 바로 안 오고 "진행 중..." 표시가 잠깐 뜬다.
3. 왼쪽 챗봇 화면에서는 세션이 여러 개 쌓인다 — 네비의 "챗봇" 항목 아래 목록에서 과거 대화를 클릭해 다시 열거나, "수정"으로 제목을 바꾸거나, "닫기"로 목록에서 지울 수 있다("닫기"는 목록에서만 지우는 것이라 대화 내용 자체는 안 지워진다).
4. 답변 아래 🗑 아이콘으로 그 메시지 하나만 지울 수 있다(마우스를 올리면 나타남).
5. **"💡 이 대화를 관심사로 등록"** 버튼 — 지금까지 나눈 대화를 바탕으로 관심사 등록 폼(제목·찾는 것·이미 아는 것·제외할 주제)을 자동으로 채워 관심사 화면으로 이동한다. 여기서 저장 버튼을 눌러야 실제로 등록된다(자동 저장 아님).

## 관심사 등록하고 논문 추천받기

**🔬 관심사** 화면.

1. "새 관심사 만들기"를 펼쳐 제목·찾는 것·이미 아는 것·제외할 주제를 적고 "만들기". (챗에서 "이 대화를 관심사로 등록"으로 왔다면 이미 채워져 있다.)
2. 등록된 관심사 카드에서 **"지금 검색"**을 누르면 그 관심사를 기준으로 논문을 찾아온다(주로 arXiv). 결과는 관련도순으로 뜨고, peer review 여부·연도·인용수도 같이 보여주지만 점수로 합치지는 않는다 — 최종 판단은 직접 표를 보고 한다. 관련 없다고 판정된 것도 표에 그대로 나온다(판정이 틀릴 수 있어서).
3. 더 보고 싶으면 **"추가 검색"**(다음 순위부터 이어서).
4. 관심사 내용을 "수정"하면 저장과 동시에 기존 후보를 새 기준으로 다시 판정해준다(재검색 아님 — 이미 찾은 것 중에서 다시 고름).
5. 카드를 펼치면 "보유·추천 논문" 목록에서 이 관심사에 지금까지 걸린 논문 전체를 볼 수 있다.
6. "삭제"로 관심사를 지우면 그 관심사가 걸어둔 추천 기록도 같이 지워진다.

## 논문 등록하고 추출 결과 보기

**📄 논문** 화면.

**등록하는 방법 두 가지**

- **업로드**: PDF 파일을 고르고, DOI나 arXiv id를 알면 같이 적는다(자동으로 서지정보를 가져온다). arXiv가 아닌 논문이라 제목이 자동으로 안 채워지면 "제목" 칸에 직접 입력한다. "등록"을 누르면 파일이 서버의 `library/` 폴더에 저장되고 분석(파싱·임베딩)은 백그라운드에서 진행된다.
- **`library/` 폴더에 직접 넣기**: 파일 탐색기로 서버가 도는 컴퓨터의 `library/` 폴더에 PDF를 직접 옮겨둔 뒤, 화면의 "다시 스캔"을 누르면 "library/ 폴더 — 미추적 파일" 목록에 나타난다. 여기서 "트래킹에 추가"를 누르면 그 파일이 "보유 논문"으로 등록된다.

**등록 후**

- "보유 논문" 목록에서 논문 제목을 클릭하면 펼쳐지며 저자·등록일·원본 PDF(있으면)·추출 결과가 나온다. 분석 중이면 배지("분석 중...")가 뜨고 끝나면 자동으로 갱신된다.
- 추출 결과(핵심 주장·근거·저자가 스스로 밝힌 한계·미해결 지점)는 처음 펼칠 때 그 자리에서 만들어지고(LLM 호출 1회, 시간이 좀 걸릴 수 있음) 이후로는 캐시된 걸 바로 보여준다. **추출 결과를 고치는 기능은 없다** — 잘못됐으면 재등록한다.
- 원본 PDF는 등록 당시 파일이 `library/`에 남아 있어야 볼 수 있다. 파일을 지우거나 옮기면 "⚠️ library/에서 이 파일을 찾을 수 없습니다" 경고가 뜬다 — 원래 자리로 되돌리거나 "다시 스캔" 후 재등록한다.

## 실험도구 등록하기

**🧪 실험도구** 화면. "새 실험도구 등록"을 펼쳐 이름·목적·세부내용·주의사항을 적고 등록한다. **주의사항은 연구 워크플로우가 자동으로 읽는다** — 실험 설계 단계에서 이 장비 이름이 나오면 안내 문구 맨 앞에 주의사항을 붙여준다. 목록에서 "수정"/"삭제"로 관리한다.

## 지식 노트 작성하기

**📝 지식 노트** 화면. "새 노트 작성"을 펼쳐 제목·본문을 적고 저장한다. 본문은 검색에도 쓰인다(챗·연구 워크플로우가 참고자료로 찾아볼 수 있음) — 본문을 고치면 검색용 색인도 다시 만들어지지만, 제목만 바꾸면 색인은 그대로 둔다. 목록에서 "수정"/"삭제"로 관리한다.

## 연구 워크플로우로 연구 진행하기

**🧬 연구 워크플로우** 화면. 연구 주제 하나를 정하면 **가설 수립 → 실험 설계 → 실험 운영 → 실험 보고서 → 논문 초안** 순서로 이어서 진행한다. 각 단계는 사람이 직접 다음으로 넘길 때만 진행되고(자동으로 안 넘어감), 지나온 과정이 전부 남아 있어 돌아가서 다시 볼 수 있다.

1. **새 연구 시작**: 왼쪽 네비 "연구 워크플로우" 옆 `+`를 누르거나, 화면에서 연구 주제·질문을 적고 "시작". 가설과 그 근거, 검증 가능한 예측이 나온다.
2. **다음 단계 고르기**: 화면 아래 "다음으로 갈 수 있는 곳"에 갈 수 있는 방향이 작은 다이어그램 행으로 나열된다(추천은 밝은 테두리로 강조). 하나를 클릭하면 그 아래에 필요한 입력창이 뜬다 — 그냥 다음 단계로 진행하는 것도 있고, 실험 결과를 입력해야 하는 것도 있고, 이전 단계를 다시 하는 것(재시도)도 있다.
   - **재시도**: AI에게 방향을 글로 지시하거나("더 간단한 장비로" 등), "직접 수정"을 펼쳐 그 단계의 필드를 손으로 고칠 수 있다. 단, 재생성하면 그 뒤 단계에 이미 만들어둔 내용은 자동으로 안 지워지고 낡은 채로 남는다는 경고가 뜬다.
3. **실험 설계 → 실험 운영**: 실험은 직접 진행한다 — 이 화면은 설계를 짜주고, 실제 결과를 입력하면 가설이 맞았는지·실험 자체에 문제가 있었는지·다시 해봐야 하는지를 판단해줄 뿐이다.
4. **논문 초안 단계**: 제목·초록·서론·방법·결과·고찰이 채워진다. "✎ 수정"을 누르면 그 자리에서 바로 고칠 수 있다(저장하면 반영). `[CITE:논문id]`처럼 보이는 건 인용 마커 — 평소엔 서지 형식으로 바뀌어 보이고, 수정 모드에서만 원문 그대로 보인다(지우면 인용이 깨지니 그대로 둔다).
5. **참고문헌**: 각 단계에서 필요하면 자동으로 관련 논문을 찾아 참고문헌에 추가한다. 화면 아래 "참고문헌 (N편)"을 펼치면 지금까지 모인 목록이 보인다. 검색이 부실했다 싶으면 그 부분만 독립적으로 다시 돌릴 수 있는 버튼도 있다(참고문헌만 재시도, 이미 만든 본문은 안 건드림).
6. **과거 시점으로 돌아가기**: 위쪽 히스토리("펼치기, 기록 N개")에서 과거 체크포인트를 클릭하면 그 시점의 내용을 볼 수 있다. 과거 시점에서 "다음으로 갈 수 있는 곳"을 다시 고르면 거기서부터 새 갈래로 갈라진다 — 원래 갈래는 사라지지 않고 히스토리에 그대로 남는다.
7. **메모**: 각 시점마다 "📝 메모"에 장비 주의사항이나 다음에 시도할 것을 자유롭게 적어둘 수 있다. `▾`/`▸`로 접었다 펼 수 있다.
8. **세션 관리**: 왼쪽 네비 "연구 워크플로우" 아래 목록에서 진행 중인 연구를 여러 개 오가며 관리한다(수정/닫기는 챗봇 세션과 같은 방식).

## 라이브러리 백업 · 다른 기기로 옮기기

**⚙️ 설정** 화면 아래쪽.

- **내보내기**: 세 가지 범위 중 고른다 — "공유용"(서지·상태·관심사·노트만, 원본 PDF 제외라 저작권 안전) / "기기 이전용"(+검색 인덱스, 새 기기에서 재파싱 없이 복원) / "완전 백업"(+원본 PDF까지, 파일이 가장 큼). 누르면 ZIP이 바로 다운로드된다.
- **가져오기**: 내보낸 ZIP을 골라 "가져오기". **새로 설치해서 아무 데이터도 없는 상태에서만 된다** — 논문·관심사·실험도구·노트 중 하나라도 이미 있으면 거부된다(기존 데이터와 합치는 기능은 없음, 덮어쓰기 방지). 검색 인덱스까지 같이 가져왔다면 앱을 재시작해야 검색·추출이 정상 동작한다(화면에 안내 문구가 뜬다).

## API 키 설정

**⚙️ 설정** 화면 위쪽. 여기서 입력한 Gemini/Claude 키는 이 컴퓨터에 저장되고 서버 재시작 없이 바로 다음 질문부터 적용된다. 입력하지 않으면 서버의 `.env` 값을 그대로 쓴다. `Qwen-tuned`(로컬 모델)는 키가 필요 없다.

## 자주 겪는 상황

- **논문 분석이 "분석 중..."에서 안 넘어간다**: 서버가 재시작되면 진행 중이던 분석이 멈춘 채로 표시만 남을 수 있다(아직 자동 재시도 기능 없음, [docs/RoadMap.md](RoadMap.md) 예정 항목). 지금은 해결 방법이 없으니 겪으면 알려달라 — 실사용 빈도를 보고 우선순위를 정한다.
- **관심사 검색 결과가 0건으로 너무 빨리 끝난다**: 한글 제목·키워드는 자동으로 영어로 변환해서 검색하지만(관심사 제목이 한글이면 자동 처리), 그래도 안 나오면 검색어 자체가 너무 좁거나 arXiv에 없는 주제일 수 있다.
- **모델 답변이 이상하거나 안 온다**: 그 모델의 쿼터가 소진되면 자동으로 다른 모델로 전환된다 — 화면의 "💬" 옆 부가 설명(comment)에 전환 여부가 안내된다. 두 모델 다 실패하면 세션 전체에서 그 모델들이 잠깐 막힐 수 있다(다음 대화부터 자동 해제 전까지는 안 보일 수 있음).
