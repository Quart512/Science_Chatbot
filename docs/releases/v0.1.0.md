## 새 기능

첫 릴리즈다 — 지금까지 만든 기능 전부가 "새 기능"이다.

- **과학 Q&A** — 등록해둔 자료와 웹 검색을 근거로 과학·수학 질문에 답한다. 답이 부족하면 스스로 점검해 다시 찾아 고쳐 쓴다.
- **논문 추출기** — PDF나 DOI·arXiv 번호로 논문을 등록하면 핵심 주장·근거·저자가 스스로 밝힌 한계·아직 안 풀린 문제를 자동으로 뽑아 정리한다. 등록된 논문은 챗이 답할 때 근거로 인용한다.
- **관심사 · 추천 검색** — 찾는 것·이미 아는 것·제외할 주제를 등록해두면 arXiv에서 관련 논문을 찾아 추천한다.
- **연구 워크플로우** — 가설 수립 → 실험 설계 → 실험 운영 → 실험 보고서 → 논문 초안까지 단계별로 진행한다. 각 단계는 사람이 직접 다음으로 넘길 때만 진행되고, 지나온 과정이 전부 남아 되돌아볼 수 있다.
- **실험도구 · 지식 노트** — 보유 장비와 개인 메모를 등록해두면 연구 워크플로우와 챗이 참고한다.
- **라이브러리 백업/이전** — 공유용·기기 이전용·완전 백업 세 가지 범위로 내보내고, 새 기기에서 가져올 수 있다.

## 알려진 제한

- **Windows 실행 파일(`start.bat`)이 아직 실기 검증 전이다.** macOS·Linux·Docker는 확인됐지만 Windows는 이 릴리즈로 처음 실사용 검증한다 — 문제가 있으면 이슈로 알려달라.
- **Intel Mac은 portable 번들을 못 쓴다** — 이 프로젝트가 요구하는 파이썬 버전에서 `onnxruntime`이 macOS x86_64 wheel을 안 만든다. Docker 버전을 대신 쓴다.
- 다운로드 링크는 HTTP만 지원한다(랜딩 페이지에 아직 HTTPS 미적용, 다운로드 자체는 GitHub Releases라 무관).
