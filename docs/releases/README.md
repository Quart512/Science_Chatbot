# 릴리즈 노트

태그(`vX.Y.Z`)를 push하기 전, 이 폴더에 같은 이름의 파일(`vX.Y.Z.md`)을 먼저 만든다.
`release.yml`이 `gh release create` 시 이 파일을 찾아서 있으면 `--notes-file`로,
없으면 `--generate-notes`(커밋 로그 자동 요약)로 폴백한다 — 릴리즈 노트를 미리
안 써놔도 자동화가 끊기지 않는다.

작성 방법: `TEMPLATE.md`를 복사해 `vX.Y.Z.md`로 저장하고 채운다. 이번 릴리즈에서
실제로 뭐가 바뀌었는지는 `docs/RoadMap.md` 완료 표의 해당 기간 항목을 보고 요약하면
된다 — RoadMap이 이미 정본이라 여기서 새로 조사할 필요는 없고, 사용자에게 중요한
것만 추려서 옮겨 적는 요약 작업에 가깝다.
