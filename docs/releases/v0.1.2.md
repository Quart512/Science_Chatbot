v0.1.1에서 드러난 **Windows 한국어 환경 문제**를 고친 릴리즈다. 한국어 Windows를 쓴다면
이 버전으로 올리는 걸 권한다.

## 버그 수정

- **Windows에서 챗이 답을 못 하고 죽던 문제** — 이번 릴리즈의 핵심이다.
  한국어 Windows는 기본 문자 인코딩이 `cp949`인데, 여기엔 줄표(`—`)가 아예 없다.
  AI 답변에 이 문자가 섞이는 순간 서버가 로그를 남기다가 오류를 내고 답변이 통째로
  실패했다. 연구 워크플로우는 되는데 챗만 안 되던 원인이 이것이었다.
  이제 로그를 항상 UTF-8로 남기고, 어떤 문자가 와도 로그 때문에 답변이 실패하지 않는다.
- **앱 안내 창의 한글이 깨져 보이던 문제** — "8000번 포트를 다른 프로그램이 이미
  쓰고 있습니다" 같은 안내가 알 수 없는 글자로 나왔다. 실행 스크립트 파일의 인코딩
  표시가 빠져 있어 Windows가 다른 문자표로 읽던 것이라, 표시를 넣어 해결했다.
- **답변이 실패하면 새 대화가 왼쪽 목록에 안 나타나던 문제** — 대화 자체는 만들어져
  있는데 목록만 갱신이 안 되고 있었다. 이제 성공·실패와 무관하게 목록에 바로 나타난다.

## 알려진 제한

- 앱을 끄고 **바로** 다시 켜면 "8000번 포트를 다른 프로그램이 이미 쓰고 있습니다"가
  뜰 수 있다. 이전 서버가 아직 완전히 종료되지 않은 것이니 10~20초 뒤에 다시 켜면 된다.
  (이 안내 문구가 v0.1.1까지는 깨져 보였다.)
- **여전히 코드 서명이 안 돼 있어 첫 실행 시 보안 경고가 뜬다.** 압축을 푼 폴더의
  `README.txt`에 넘기는 방법이 적혀 있다.
- **Intel Mac은 portable 번들을 못 쓴다** — Docker 버전을 대신 쓴다.
- **macOS는 앱 폴더를 바탕화면·문서·다운로드 폴더 안에 두면 실행이 실패할 수 있다.**
  사용자 폴더 바로 밑이나 별도 폴더로 옮겨서 실행한다.
