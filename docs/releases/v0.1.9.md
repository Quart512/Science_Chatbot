"업데이트해도 화면이 예전 버전 그대로"의 진짜 원인을 마저 잡은 릴리즈다. v0.1.8로도
안 끝났던 이유가 있었다.

## 버그 수정

- **업데이트해도 화면이 예전 버전 그대로이던 문제 (근본 원인)** — 앱 창을 닫아도
  브라우저 자체는 macOS에서 자동으로 안 꺼진다는 점이 원인이었다. 완전히 안 꺼진
  브라우저가 남아있으면 다음 실행이 그걸 재사용해서 새 화면을 안 불러왔다. 이제
  앱 창을 닫을 때 브라우저까지 확실히 같이 끄고, 실행할 때도 혹시 남아있는 게
  있으면 먼저 정리한 뒤 새로 연다.

## 개선

- **설정 화면에서 첫 실행 안내창을 다시 볼 수 있다** — API 키 안내, 사용법 가이드,
  사용 데이터 공유 동의를 처음 봤던 그 화면을 "처음 안내 화면" 카드의 "다시 보기"로
  언제든 다시 열 수 있다.

## 알려진 제한

- **Windows는 아직 터미널 설치를 지원하지 않는다** — 압축 파일을 받아 실행하면 되고,
  이때 뜨는 보안 경고는 `README.txt`의 안내대로 넘긴다.
- **압축 파일을 직접 받아 쓰는 경우(macOS)** — `AIsaac.app` 승인이 필요하고, 승인한 뒤
  폴더를 다른 곳으로 옮기면 승인이 풀려 다시 안 열릴 수 있다. 옮길 계획이면 **옮긴 뒤에**
  승인하거나, 터미널 설치를 쓰는 편이 낫다.
- **로컬 모델은 품질이 낮다.** 앱이 도는지 확인하는 용도이고, 질문한 언어와 다른 언어로
  답하거나 과학과 무관한 질문을 걸러내지 못하는 등 정상 동작하지 않을 수 있다.
- **Intel Mac은 portable 번들을 못 쓴다** — Docker 버전을 대신 쓴다.
