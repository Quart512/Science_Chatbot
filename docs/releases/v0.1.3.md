v0.1.2 이후 실사용 피드백을 모아 반영한 릴리즈다. 논문 관리·검색·설정 화면이 전반적으로
다듬어졌고, Windows에서 앱을 껐다가 바로 다시 켤 때 걸리던 문제도 해결됐다.

## 새 기능

- **논문 카탈로그에서 논문 삭제** — 더 이상 필요 없는 논문을 목록에서 지울 수 있다.
  (원본 PDF 파일 자체는 지우지 않는다 — 목록에서만 제거)
- **설정 화면에 연결 정보·버전·릴리즈 노트 표시** — 지금 앱이 어떤 주소로 떠 있는지,
  어떤 버전인지, 이번 업데이트로 뭐가 바뀌었는지를 앱 안에서 바로 확인할 수 있다.
- **과학과 무관한 질문에는 정중히 안내** — 챗봇이 점심 메뉴 추천 같은 일상 질문을
  받으면 무리해서 답하는 대신, 과학 관련 질문에 특화된 어시스턴트임을 안내한다.

## 개선

- **논문 검색이 파일명으로도 된다** — 서지정보(제목)를 못 찾아 등록된 논문은 화면에
  파일명이 표시되는데, 지금까지는 그 이름으로 검색이 안 됐다.
- **PDF 뷰어 버튼 역할을 명확히 구분** — "원본 보기"(그 자리에서 펼치기)와 "전체화면으로
  보기"가 각각 뚜렷한 버튼으로 나뉘었다.
- **라이브러리 내보내기 옵션 설명 강화** — 공유용·기기 이전용·완전 백업 세 옵션이
  서로 어떻게 다른지 화면에서 바로 읽을 수 있다.
- **지식노트 작성 폼이 화면 크기에 맞춰 커진다** — 창을 넓히면 입력창도 같이 커진다.
  또한 노트 미리보기가 긴 텍스트에도 박스를 벗어나지 않도록 수정됐다.
- **랜딩 페이지 애니메이션이 화면 중앙 근처에서 그려지도록 수정** — 예전에는 스크롤
  중 화면 밖으로 벗어나 보이지 않는 구간이 있었다.
- **Windows에서 포트가 막혀도 자동으로 다음 포트를 사용** — mac/Linux에는 이미 있던
  기능이 Windows에도 적용됐다. 앱을 켠 채로 다시 실행하면 새 서버를 띄우는 대신
  이미 떠 있는 창을 다시 열어준다.

## 버그 수정

- **API 키를 대화 중간에 입력해도 계속 막히던 문제** — 키를 안 넣고 질문했다가 나중에
  설정에서 키를 입력해도, 같은 대화(세션)에서는 계속 "키가 없다"는 오류가 반복됐다.
  이제 다음 질문부터 바로 정상 동작한다.

## 알려진 제한

- **여전히 코드 서명이 안 돼 있어 첫 실행 시 보안 경고가 뜬다.** 압축을 푼 폴더의
  `README.txt`에 넘기는 방법이 적혀 있다.
- **Intel Mac은 portable 번들을 못 쓴다** — Docker 버전을 대신 쓴다.
- **macOS는 앱 폴더를 바탕화면·문서·다운로드 폴더 안에 두면 실행이 실패할 수 있다.**
  사용자 폴더 바로 밑이나 별도 폴더로 옮겨서 실행한다.
