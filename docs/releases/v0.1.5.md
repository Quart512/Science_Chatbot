macOS에서 앱 자체가 안 켜지던 문제를 고친 릴리즈다. 첫 실행 화면도 새로 생겼고, API 키가
없어도 일단 챗봇을 써볼 수 있는 방법도 추가됐다.

## 새 기능

- **API 키 없이도 챗봇을 써볼 수 있다** — 설정 화면에서 "로컬 모델"을 받으면(약 1GB)
  API 키 없이 챗 질문이 동작한다. 다만 품질은 많이 낮다 — 앱이 도는지 확인하는 용도로
  보면 되고, 질문한 언어와 다른 언어로 답하는 경우도 있다. 실제로 연구에 쓸 때는
  API 키를 넣는 걸 권한다.
- **첫 실행 안내 화면** — 앱을 처음 켜면 API 키를 어디서 넣는지, 사용법 가이드는
  어디 있는지 바로 안내한다. 사용 데이터 공유 여부도 이 화면에서 정할 수 있다
  (나중에 설정 화면에서 언제든 바꿀 수 있다).

## 개선

- **앱 창이 훨씬 빨리 뜬다** — 예전에는 첫 실행 시 검색용 AI 모델(약 2GB)을 다
  받을 때까지 창 자체가 안 열렸다. 이제 창은 바로 뜨고, 모델은 화면 아래 진행률
  표시와 함께 뒤에서 계속 받는다. 다 받기 전까지는 질문·검색이 응답을 기다린다.

## 버그 수정

- **macOS에서 앱이 아예 안 켜지거나, 켜져도 계속 멈춰 있던 문제** — 이번 릴리즈의
  핵심이다. `AIsaac.app`을 "그래도 열기"로 한 번 승인해도, 그 안에서 실제로 쓰는
  라이브러리 파일들이 하나씩 따로 막히면서("Mac을 보호하기 위해 ...을 차단했습니다")
  실행이 멈추는 경우가 있었다. 이제 `.app` 승인 한 번이면 나머지는 앱이 알아서
  처리한다.

## 알려진 제한

- **처음 열 때 승인이 두 번 뜰 수 있다** — ① "Apple은 악성 코드가 없는지 확인할 수
  없습니다"(코드 서명이 아직 안 돼 있어서 뜨는 정상 경고, README의 안내대로 "그래도
  열기"로 넘기면 된다), ② "'applet'에서 'Google Chrome'을 제어하려고 합니다"(앱
  창을 닫을 때 서버도 같이 끄기 위한 정상 권한 요청, 허용을 누르면 된다). 둘 다
  한 번만 승인하면 다음부터는 안 뜬다.
- **로컬 모델은 품질이 낮다.** 자체 평가에서 낮은 점수를 받았고, 질문한 언어와 다른
  언어로 답하거나 논문 분석·추천 같은 기능이 정상 동작하지 않을 수 있다.
- **Intel Mac은 portable 번들을 못 쓴다** — Docker 버전을 대신 쓴다.
- **macOS는 앱 폴더를 바탕화면·문서·다운로드 폴더 안에 두면 실행이 실패할 수 있다.**
  사용자 폴더 바로 밑이나 별도 폴더로 옮겨서 실행한다.
