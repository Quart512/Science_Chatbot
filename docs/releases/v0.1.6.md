설치가 훨씬 쉬워진 릴리즈다. macOS에서 보안 경고를 아예 안 만나는 설치 방법이 생겼고,
앱을 업데이트해도 화면이 예전 그대로이던 문제도 고쳤다.

## 새 기능

- **터미널 한 줄로 설치 (Mac · Linux)** — 아래 명령을 붙여넣으면 보안 경고 없이 설치된다.
  설치 위치도 알아서 정해지고(`~/AIsaac`), 이미 설치돼 있으면 논문·노트·대화 기록·받아둔
  모델을 그대로 두고 앱만 새 버전으로 바꾼다.

  ```
  curl -fsSL https://raw.githubusercontent.com/Quart512/AIsaac/main/scripts/install.sh | bash
  ```

  기존처럼 압축 파일을 직접 받아도 되지만, 그 경우엔 예전과 같이 보안 경고를 넘기는
  절차가 필요하다.

## 버그 수정

- **업데이트해도 화면이 예전 버전 그대로이던 문제** — 새 버전을 받아 실행해도 설정 화면에
  새 항목이 안 보이거나 화면이 이전과 똑같았다. 브라우저가 예전 화면을 계속 재사용해서
  생긴 문제이고, 이제 앱을 열 때마다 최신 화면을 확인한다. (v0.1.5 이전부터 있던
  문제라, 이번 버전부터 업데이트가 제대로 반영된다.)
- **로컬 모델 받기 진행률이 2초 만에 100%가 되던 문제** — 실제로는 1GB를 더 받는 중인데
  진행률만 다 찬 것처럼 보였다. 이제 실제 진행 상황이 표시된다.
- **다 받은 직후 잠깐 동안 로컬 모델을 고르면 실패하던 문제** — 파일을 다 받은 뒤에도
  모델을 메모리에 올리는 시간이 몇 초 더 필요한데, 그 사이 이미 준비된 것처럼 보였다.
  이제 그 구간이 "모델 불러오는 중"으로 표시된다.

## 알려진 제한

- **Windows는 아직 터미널 설치를 지원하지 않는다** — 압축 파일을 받아 실행하면 되고,
  이때 뜨는 보안 경고는 `README.txt`의 안내대로 넘긴다.
- **압축 파일을 직접 받아 쓰는 경우(macOS)** — `AIsaac.app` 승인이 필요하고, 승인한 뒤
  폴더를 다른 곳으로 옮기면 승인이 풀려 다시 안 열릴 수 있다. 옮길 계획이면 **옮긴 뒤에**
  승인하거나, 위 터미널 설치를 쓰는 편이 낫다.
- **로컬 모델은 품질이 낮다.** 앱이 도는지 확인하는 용도이고, 질문한 언어와 다른 언어로
  답하거나 논문 분석·추천 기능이 정상 동작하지 않을 수 있다.
- **Intel Mac은 portable 번들을 못 쓴다** — Docker 버전을 대신 쓴다.
