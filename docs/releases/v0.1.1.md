v0.1.0을 실제로 써보고 나온 문제들을 고친 릴리즈다.

## 버그 수정

- **챗이 아무 말 없이 죽고, 방금 보낸 질문까지 화면에서 사라지던 문제** — 가장 큰 수정이다.
  답변 생성 중 오류가 나면(API 키 없음·키가 잘못됨·모델 한도 초과 등) 아무 표시 없이
  대화 블록이 통째로 사라졌다. 이제 **무엇이 잘못됐는지 화면에 그대로 뜨고**, 보낸 질문도
  사라지지 않는다. 서버 연결이 끊긴 경우도 마찬가지로 안내가 뜬다.
- **API 키 없이 챗을 쓰면 경고가 안 뜨던 문제** — 위와 같은 원인이었다. 이제
  "설정 화면에서 API 키를 확인해주세요" 안내가 뜬다.
- **작업 표시줄·창 아이콘이 보라색 번개 모양으로 뜨던 문제** — 템플릿에 딸려온 임시
  아이콘이 그대로 남아 있었다. AIsaac 로고(프리즘 + 무지개 궤도)로 교체했다.

## 개선

- **처음 실행할 때 뜨는 보안 경고를 넘기는 방법을 README에 추가했다.** 압축을 푼 폴더 안
  `README.txt`를 보면 된다.
  - Windows: 다운로드 경고("계속"/"유지")와 실행 경고("추가 정보" → "실행")
  - macOS: "Apple은 악성 코드가 없음을 확인할 수 없습니다"로 안 열릴 때
    (우클릭 → 열기, 또는 시스템 설정 → 개인정보 보호 및 보안)
- 앱 곳곳에 남아 있던 "물리"를 **"과학"**으로 정리했다. 챗은 원래부터 과학·수학 전반을
  다루는데 화면 문구만 물리로 남아 있어 좁아 보였다.

## 알려진 제한

- **여전히 코드 서명이 안 돼 있어 첫 실행 시 보안 경고가 뜬다.** 위 README 안내대로 한 번만
  허용하면 된다. 정식 서명은 이후 릴리즈에서 다룬다.
- **Intel Mac은 portable 번들을 못 쓴다** — `onnxruntime`이 이 프로젝트가 요구하는 파이썬
  버전용 macOS x86_64 wheel을 만들지 않는다. Docker 버전을 대신 쓴다.
- **macOS는 앱 폴더를 바탕화면·문서·다운로드 폴더 안에 두면 실행이 실패할 수 있다.**
  사용자 폴더 바로 밑이나 별도 폴더로 옮겨서 실행한다(README.txt에도 적혀 있다).
- Windows 실기 검증은 v0.1.0에서 처음 진행했고, 이 릴리즈로 이어서 확인 중이다.
